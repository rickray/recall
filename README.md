# Recall

Focused adult cognitive training and memory games in a fast, minimal, mobile-first web app.

**Live URL**: [https://rickray.github.io/recall/](https://rickray.github.io/recall/)

---

## Games

- **Sequence**: Simon-style progressive auditory and visual sequential recall.
- **N-back**: Working memory training matching stimuli against items presented *N* steps back.
- **Spatial Grid**: Visuospatial pattern recall across coordinate matrix boards.
- **Even Factors**: Calm multiplication drill where both factors end in an even digit (0, 2, 4, 6, 8) and at least one factor is a single digit (2, 4, 6, 8).

---

## Design Principles

- **Adult Aesthetics**: Clean, modern dark theme—no cartoon animals, juvenile styling, or gamified bloat.
- **Mobile-First & One-Handed**: Big touch targets and optimized thumb zone navigation for comfortable phone play.
- **No Friction**: Instant access, zero account creation, zero tracking, no ads, and no in-app purchases.
- **Pure Static Stack**: Pure HTML/CSS with zero build steps and lightning-fast loading on GitHub Pages.
